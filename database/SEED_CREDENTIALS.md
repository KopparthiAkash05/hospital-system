# Seeded doctor credentials

Demo logins for the doctors added by `scripts/seed_doctors.py`.
Generated by `python scripts/seed_doctors.py --emit-docs`.

## Pattern

| Field | Value |
| --- | --- |
| Email | `<name>@gmail.com` (lower case, no spaces) |
| Password | `doctor123<name>` (lower case, no spaces) |
| Phone | demo placeholders from the 89 / 63 / 78 mobile blocks |

Example: Dr. Ananya Sharma -> `ananyasharma@gmail.com` / `doctor123ananyasharma`.

> The phone numbers are demo placeholders. They use the 89 / 63 / 78
> mobile blocks with a zero padded tail so they read as test data;
> they are not meant for real calls or SMS.

> These are demo accounts for a development database. Change the
> passwords before using any of this data in a real deployment.
